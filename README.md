## Setup Instructions

1. Install Git on your computer.
2. Clone the repository:

   ```bash
   git clone https://github.com/V330304234/COMP3104_Group32_Assignment.git
   ```

3. Navigate into the repository:

   ```bash
   cd COMP3104_Group32_Assignment
   ```

4. Check the available branches:

   ```bash
   git branch -a
   ```

5. Switch to your assigned branch:

   ```bash
   git checkout YOUR-BRANCH-NAME
   ```


## CI/CD Pipeline
GitHub Actions automatically runs the CI workflow whenever changes are pushed to the repository. 

## Branching Strategy
Each group member works on an individual branch. Changes are pushed and merged into main branch through pull requests.
