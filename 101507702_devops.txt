DevOps combines software development and IT operations to improve the software delivery process.

It promotes collaboration, automation, continuous integration, and continuous delivery.

COMP3104 introduces tools and practices used to build, test, and deploy software efficiently.

DevOps also helps automate testing, deployment, and monitoring throughout the software development process.

Version control and CI/CD are important DevOps practices because they help teams manage changes and automate software delivery.

Git and GitHub support DevOps by tracking changes and helping team members collaborate on the same project.
